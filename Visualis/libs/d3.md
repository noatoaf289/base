## What this library does
- D3 is a low-level visualization toolkit built around data joins.
- It transforms data into DOM/SVG/canvas representations via functional mapping.
- Its power comes from composable modules: selection, scale, axis, shape, transition, force, zoom.

## Comprehensive options and additional API references
- **Signature:** `d3.select(selector: string)`
  - **What it does:** Selects first matching DOM element.
  - **Example:**
```js
const svg = d3.select('#chart').append('svg')
```
- **Signature:** `selection.data(data, key?)`
  - **What it does:** Binds array data to a selection; key stabilizes identity.
  - **Example:**
```js
svg.selectAll('circle').data(points, d => d.id)
```
- **Signature:** `selection.join(enter, update?, exit?)`
  - **What it does:** Applies enter/update/exit logic in one call.
  - **Example:**
```js
sel.join(e=>e.append('rect'), u=>u, x=>x.remove())
```
- **Signature:** `d3.scaleLinear().domain([min,max]).range([a,b])`
  - **What it does:** Creates numeric mapping for positions/sizes.
  - **Example:**
```js
const x = d3.scaleLinear().domain([0,100]).range([0,400])
```
- **Signature:** `d3.axisLeft(scale)`
  - **What it does:** Generates left-axis renderer for an SVG group.
  - **Example:**
```js
svg.append('g').call(d3.axisLeft(y))
```
