# Font Awesome Free Icons Reference

## Placeholder tag and where to put it
- Placeholder tag: `<Library:FontAwesome />`
- Put it inside `<head>`.
- This placeholder injects both CSS and JavaScript assets for Font Awesome.

Generated from Font Awesome 6.x metadata. Each icon is available in the **free** set.

## Usage

- **CSS:** Use class `fa-solid fa-<name>`, `fa-regular fa-<name>`, or `fa-brands fa-<name>`.
- **Files:** `libs/font-awesome/css/all.min.css`, `libs/font-awesome/js/all.min.js`, `libs/font-awesome/webfonts/`.
